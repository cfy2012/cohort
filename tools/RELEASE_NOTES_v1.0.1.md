# Cohort v1.0.1

- 实验目录只留 `experiments/lab`：旧的 `rheostat` / `circuit` 单页骨架并进来了，目录已删除。
- 排课时每节课都能选「本节实验室」：不开放 / 自由实验台 / 自定义实验室 / 内置模块，学生点「进实验室」直接进对应的那一间。
- 控制台「实验室」页把「自定义实验室」提到最前面（总实验室），页签设置和说明依次排后面。
- 新增安卓端（`android/`）：一套 WebView 壳出两个 APK，GitHub Actions 自动构建。
  - `Cohort-讲台-1.0.1.apk`（教师端，手机看控制台）
  - `Cohort-学生端-1.0.1.apk`（学生端，填地址 + 学号姓名直接进课堂）
- Windows 安装包重打，装的就是这版。

安卓端是客户端，不是服务器：服务仍然跑在老师这台 Windows 上，手机连同一个 Wi-Fi。
