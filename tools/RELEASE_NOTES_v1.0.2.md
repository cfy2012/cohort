# Cohort v1.0.2 · 语音输入

所有能打字的地方，现在都能说话了。识别在本机跑，不联网。

## 新增：语音输入

- 学生提问框、教师端「名单设置 / 排课 / AI 引擎」里的文本框、实验室的笔记框和 AI 对话框，右上角都多了一个「语音」按钮：点一下开始录，按钮变红并计时；再点一下收尾，识别结果直接接在原有文字后面。
- 识别引擎是 **whisper.cpp** 的 `whisper-cli.exe` + `ggml-base-q5_1.bin` 量化模型，全部放在 `runtime/asr`，**跟着安装包一起装好，不需要联网、不需要额外下载**。
- 中文默认会吐繁体，服务端加了一层字级繁转简（`web/app/t2s.json`，4300+ 字对），出来就是简体。
- whisper 起不来时自动退到系统自带的 SAPI 识别器（`CohortAsr.exe`）兜底，功能不至于整块掉。
- 单句最长 60 秒，录音在浏览器里降采样成 16 kHz 单声道 16 bit WAV，POST 到 `/api/asr`（限 12 MB）。临时 wav 只保留最近 200 个。

## 安装包变化

- `Cohort-Setup-1.0.2.exe`：53.85 MB → **109 MB**，多出来的就是 whisper 可执行文件和 base 量化模型。
- 安卓两个 APK 本轮没有改动（语音走的是服务端同一个接口，壳不用重打），继续沿用 v1.0.1 的产物。

## 用法

1. 装好教师端，正常启动，浏览器打开 `https://<本机IP>/`。
2. 第一次点「语音」时浏览器会问麦克风权限，允许即可。
3. 识别要几秒（base 模型，3 秒音频在本机约 7 秒出字），按钮会显示 `识别中…`。

## 备注

- 麦克风权限必须走 HTTPS 或 `127.0.0.1`，局域网里用 `http://<IP>` 打开时浏览器会拒绝录音——请用教师端自带的 `https://` 入口。
- 这一版没有引入任何新依赖：后端还是纯 PHP，识别是本地进程调用。
