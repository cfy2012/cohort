# Cohort v1.0.3 · 班级、外部 AI、按课封锁实验室

这一版把「班级 / 名单」和「AI 设置」两页真正用起来了，实验室也改成按课开放。

## 修好的

- **新建班级点了没反应**：班上一个班都没有时，前端打开弹窗会自己递归自己，永远打不开。已改掉。
- **接口偶发卡住**：老师端同时打好几个接口时，一个慢请求握着 PHP 会话文件锁，别的全排队。现在读完身份立刻放锁，班级、设置这些接口恢复毫秒级。
- **默认班级不跟着走**：系统设置里的「默认班级」原来是自由文本框，跟班级列表没关系；现在是下拉框，跟着班级列表走，班级卡片上还能一键「设为默认」。

## 班级

- 新建 / 编辑 / 删除班级，编辑时可以**直接勾选成员**（勾谁就是谁），也能合并别的班。
- 卡片上显示人数、建班日期、`默认` 徽标；同名班级不会重复建，也不会因为没勾人把原名单清空。

## 外部 AI

- 设置里新增 `API Key`，只写在本机 `data/config.json`，学生端读不到。
- AI 地址支持填 `https://api.xxx.com` 或带 `/v1` 的完整地址（自动去重），有 key 时自动带 `Authorization: Bearer …`。
- 新增「测试连接」：直接返回延迟和可用模型清单，地址错、key 错、模型名拼错能一眼看出来。
- 本机 LM Studio 的用法没变，key 留空即可。

## 实验室按课开放

- 排课弹窗里改成「本节开放的实验室」多选：勾几间就开几间，可以只勾一间。
- 学生端 `/exp/lab` 只显示本节课勾选的实验室，其余页签不出现；顶部写「本节课：温度 · 水温变化实验室」，标题同步。
- 一节课没选实验室时，仍按全局的实验室开关走。

## 安装包

- `Cohort-Setup-1.0.3.exe`：内容与 1.0.2 相同（PHP + Caddy + whisper 模型），换的是新的网页与实验代码。
- `CohortStudent-Setup-1.0.3.exe`：学生端壳，无改动，仅重打。
- `cohort-apks.zip`：安卓两个 APK 重新构建（版本号 1.0.3）。壳本身没有功能变化，它加载的仍是老师机上的页面。

## 升级方式

直接装新的安装包覆盖原目录即可，`data/` 里的班级、名单、课表、配置不会被覆盖（安装器只解包覆盖程序文件）。
